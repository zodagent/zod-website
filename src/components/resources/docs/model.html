Model & provider

Zod works with any OpenAI-compatible model. You link one provider, choose a model, and can change it from the chat at any time.

Link a provider

1

Open Settings

Press ⌘, or type in:model in the search bar.

2

Enter the address and key

For OpenRouter this is https://openrouter.ai/api/v1 and your key. For a local server on your computer, use its address (for example Ollama or LM Studio); the key can be any text.

3

Test the connection

Zod fetches the provider’s model list. If the test fails, the message says why (a wrong key, an unreachable address, a rate limit).

4

Pick a model

Choose from the list or type a model name. The composer shows the model in use and lets you change it with a search.

Choosing the model per chat

The model chip at the right of the composer opens a searchable list of the provider’s models, with the one in use first. Choosing another changes it for new messages. The Chrome extension’s side panel has the same picker at the top.

Your key

  • The key is stored in Zod’s settings on your computer.
  • It is never written into a backup, and it is sent only to the provider you linked.
  • Settings masks it by default and only shows it when you choose to.

When the model does not answer

If a provider is rate limited, out of credit or down, Zod says so in plain words in the chat and keeps your message. Without a model linked, the chat says so and links to Settings. Routines whose steps are written in the Zod language still run with no model at all.
