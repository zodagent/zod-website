Your first run

Getting started takes a few minutes.

1. Download and install

Pick your system above and run the installer. Prefer help? Book a demo and we will set it up with you.

2. Link a model

Open Settings, then Model provider, add an OpenAI-compatible API (OpenAI, OpenRouter, Ollama, LM Studio and more), press Test connection and pick a model.

3. Chat, then make it yours

Start on Home. Ask for something, make a routine, say “remember that…”.
