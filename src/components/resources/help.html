Frequently asked questions

Open Settings, then Model provider, and enter the provider's address and API key, then press Test connection. Zod works with any OpenAI-compatible endpoint: OpenAI, OpenRouter, or a local server like Ollama or LM Studio. The model list is fetched from the provider's /models endpoint, and you can change the model from the chat's model picker at any time. Read the model docs.
Your API key is stored in Zod's settings on your computer. It is never put in a backup, and it is sent only to the provider you linked. There is no Zod account, and no Zod server ever sees it. See our privacy policy
Paste a GitHub link (or a folder) on the Connectors page (in:connectors) and Zod installs the connector and starts it. Any MCP server works, and an app connector can bring its own pages, settings and tools. Each tool can be set to off, ask or allow. The agent can also add, write and remove connectors for you, asking first. Read the connectors docs
Open Connectors (in:connectors) and press Add your own, or paste the server's link. Zod starts it and speaks MCP to it, and each server's tools appear to the agent with a permission per tool. Read the connectors docs
Routines run while the Zod app is running. Each run keeps its result, and a run that was cut off by a stop is reported, not repeated. If the app was closed at a routine's time, open it and run the routine by hand, or let the next scheduled time come. Read the routines docs
Open Settings and choose Backup. Download a backup saves your chats, routines, memory, agents, skills, connectors and settings, without keys or passwords. Restore brings it back, and is how you move your setup to another computer. After a restore, link the model again.
If the docs don't cover it, the community forum is a great place to ask. Drop your question there and other users, and often the Zod team, will help you out. Visit the forum.
