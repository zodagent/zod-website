An assistant that knows the page you are on and can act on it. It pairs with the Zod desktop app, so it is the same agent, model and memory.

The side panel: a chat made for the browser

Open it from the toolbar, with Alt+Z, or from the small Zod tab on any website. It sees the page title, address and your selection, can read the page text when you ask, and uses the model, tools, memory and approvals you already set up in Zod.

See the panel

Ask about the page

Summarize it, explain a selection, find the best option, or tell the agent what to do in it.

Files, pictures and voice

Attach files, add a picture of the page, dictate, mention a memory with @ and use a skill with /.

In step with the desktop app

Chats from the panel are saved by the desktop app, and you can remember an answer or save a page to Zod's memory.

Control of Chrome itself

The agent reads pages, clicks, types, fills forms, scrolls and takes pictures in your tabs, and manages Chrome: tabs, windows, tab groups, bookmarks, history, downloads and recently closed tabs. Looking asks nothing; changing asks first.

Tabs, windows & groups

Pin, mute, move and group tabs by topic, switch windows, and bring back what you closed.

Bookmarks, history & downloads

Find that page you visited last week, tidy your bookmarks and keep track of what you downloaded.

You stay in charge

Every action that changes something asks first unless you turn Ask first off, and you can pause control from the toolbar at any time.

A Zod tab on every website

A small logo tab on the right edge of every page shows that Zod is connected, says what the agent is doing in the page, and opens the side panel. It lives in its own shadow root and reads nothing from the page. The whole Zod app opens in a tab from the toolbar when you click for it, and the toolbar icon shows a green dot while connected. Alt+Z opens the panel from anywhere.

Learn about the panel

Pairs by itself

The extension finds Zod on this computer and takes its pairing token, with nothing to paste.

Made for Chrome

It uses Chrome's own features: the side panel, tab groups, bookmarks, history, downloads and sessions. Chrome 116 or newer.

Install both ways

Get the extension from the Zod app, or the Zod app from the extension. Right-click a GitHub link to install a connector in Zod.

Your browser, now an agent.
