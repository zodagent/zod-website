Keyboard shortcuts

On Windows and Linux, ⌘ is Ctrl and ⌥ is Alt. Every shortcut can be changed in Settings, then Shortcuts.

Everywhere

⌘Kopen search
⌥Nnew chat
⌘Efocus the message box
⌘Bback to Home
⌘\toggle the sidebar (full, icons only, hidden)
⌘Ishow or hide the chat details
⌘⇧Kcompact this chat
⌘⇧Aswitch between Ask first and Auto
⌘⇧Ochoose the folder the agent works in
⌘[ ⌘]previous and next chat
⌘,Settings
