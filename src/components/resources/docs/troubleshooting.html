Troubleshooting

The common ways Zod can seem stuck, and what to do about each.

The chat says no model is linked

Open Settings, then Model provider, enter the address and key and press Test connection. Routines written as steps still run without a model.

The model did not answer

The message says why: a rate limit or a spent daily cap, an unreachable address, or a wrong key. Send again in a moment, or choose another model in the composer.

The extension is not connected

  • Make sure Zod is running on this computer, and that Browser control is on in the chat details panel.
  • Open the extension’s popup and press Connect again. If it still cannot pair, paste the token from Zod under Advanced.
  • After an update, reload the extension in chrome://extensions; Chrome grants new permissions only then.
  • The side panel needs Chrome 116 or newer.

A routine did not run

Routines run while the Zod app is running. If it was closed at the routine’s time, open it and run the routine by hand, or wait for the next time. A run cut off by a stop is reported, not repeated.

Back up before changing things

Settings, then Backup, saves your vault. A backup never contains keys, so link the model again after a restore.

Still stuck

Ask in the community forum, or book a demo and we will look at it with you.
