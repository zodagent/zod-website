Connectors & tools

Zod comes with nearly a hundred tools and a catalog of MCP servers, and you extend it by pasting a link. Apps such as Books add their own pages and tools. Anything that changes something asks first.

Built-in tools

The agent has these families of tools in every chat, and finds the rest when it needs them.

memory

Remember, recall and forget notes that persist across chats.

to-do

A list the agent keeps and ticks off as it works.

search

Find chats, pages, settings, docs and records from one bar.

files

Read and write files in your working folder, and download what it makes.

routines

Make, test, schedule and run work that repeats.

browser

Read pages and act in your Chrome tabs, with the extension.

approvals

Allow or Deny before anything that changes something.

web

Search the web and read a page.

code

Read, search, edit and test a project, and run commands when the terminal is on.

Connectors — bring your own apps

Open Connectors and paste a GitHub link or a folder. Zod installs it, starts it and shows its tools. There are four kinds: built in, app, server and pack. You can also press Add your own with a commandthat starts an MCP server. Each tool then gets a permission: off, persistent ask or allow. The agent can add, write and remove connectors for you, asking first.

Read the connectors docs

Add your own

name: Filesystem
command: npx
args: -y @modelcontextprotocol/server-filesystem ~/Documents

MCP, both ways

Zod is an MCP client to every connector, and an MCP server of its own, so tools like Claude Code can operate Zod: reads are free, a change needs confirm, and over a network it is read-only. / /

Read the connectors docs
