Agents & skills

An agent is a role with its own instructions, skills and tools. A skill is saved know-how the agent loads when a request matches.

Agents

Zod comes with ten starter agents: Researcher, Editor, Code reviewer, Planner, Bookkeeper, Coder, Browser operator, Operator, Librarian and Analyst. Open Routines, then Agents (in:agents) to see them, make your own, or change one.

  • Instructions: how the agent works, in plain words.
  • Skills: which know-how is loaded for it.
  • Tools: none picked means every tool; pick some and it gets only those, plus asking, the clock and a calculator.
  • Pages it always has: memories and docs attached by name.
  • AI assist: describe the role and let the model write or tighten the instructions.

Use an agent by mentioning it with @ in a chat, or pick one under “Who does it” in a routine. A sub-agent’s chat sits under the chat that started it.

Skills

A skill is a set of instructions saved by name, such as how you close the month. Run one by typing /name, or let the agent load it when your request matches. Open in:skills for the catalog.

  • Turn skills on or off, and make your own from a description.
  • Upload or paste a SKILL.md, or import one from GitHub.
  • AI assist writes and edits skills the same way it does agents.
