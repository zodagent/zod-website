Extensions & MCP

Zod Agent has no plugin marketplace. Instead, you extend it three ways: a built-in toolbelt, your own JavaScript custom tools, and MCP servers over HTTP.

Built-in toolbelt

Nine tools ship with the app and are offered to the model in every agent loop.

memory

Long-term markdown memory blocks that persist across sessions.

todo

Persistent to-do list — add, check, uncheck, delete, list.

calculator

Safe arithmetic with a hand-written tokenizer and parser.

clipboard

System clipboard read/write (requires browser permission).

timer

In-browser reminders that surface as a message and notification.

code_tools

JSON/YAML utilities, including the aligned YAML formatter.

confirm

Ask before destructive actions with a yes/no modal.

random

UUIDs, dice, random numbers, and WebCrypto hashes.

time

Current time, timezone conversions, and common IANA zones.

Custom tools — bring your own JavaScript

Define a tool in Settings → Tools with a name, a description, and a JavaScript implementation. Zod runs it in a sandbox with access to args, persistent ctx state, fetch, and timers. Custom tools behave identically in chat, the scheduler, and agent steps.

Read the tools docs

Settings → Tools (YAML)

tools:
  - name        : web_search
    description : Search the web for a query.
    implementation: |
      const q = sandbox.args.query;
      const res = await sandbox.ctx.fetch(`https://example.com/search?q=${q}`);
      return res.text();

MCP servers over HTTP

Declare MCP servers in Settings → MCP with a name, an HTTP URL, and optional headers. A built-in MCP-over-HTTP client (JSON-RPC initialize / tools/list / tools/call) surfaces each server's tools in the agent loop.

Read the MCP docs

Settings → MCP (YAML)

mcpServers:
  - name   : my-server
    url    : https://mcp.example.com
    headers:
      Authorization: Bearer sk-...

Extend in the docs

Everything above is configured as live YAML and persisted locally. No installs, no store.
