Vaults, settings & backup

A vault is a separate workspace with its own chats, routines, memory, agents, skills, connectors, settings and look. Settings are one clean page, and a backup captures a whole vault.

Vaults

The vault button in the title bar lists your vaults. Switch, make a new one, or edit one (name, icon, colour). Each keeps running while you are in another. A vault keeps how it looks too: folded cards, panel and composer sizes, recent searches and theme hints come back the same in any window.

Every setting can be found from the search bar by name, and every form uses one layout: a small label, a field and a clear focus ring.

Backup and restore

  • Settings, then Backup, saves chats, routines, memory, agents, skills, connectors, settings and the event ledger as one file.
  • A backup never contains your API key, tokens or passwords. After a restore you link the model again.
  • Restore is explicit and only possible on the computer Zod runs on.

Notifications

A bell and a Notifications page (⌘5) keep what Zod told you: routine runs, errors and toasts. Open one for the full detail and a button that goes to what it is about.

Where your data lives

In files on your computer, in the vault’s data folder. Nothing is sent anywhere except to the model and connectors you set up.
