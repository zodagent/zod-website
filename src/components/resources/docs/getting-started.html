Getting started with Zod

Zod is a local-first agent workspace: one app for chat, search, routines, memory and connectors, with a Chrome extension that brings it into your browser. This page takes you from first launch to your first routine.

What Zod is

Zod keeps everything on your computer. You chat with an agent that uses real tools, search chats, pages, settings and records from one bar, make routines that run on their own, and let Zod remember what matters. It works with any OpenAI-compatible model, needs no account, and asks before it changes anything.

Zod is in beta and available by invitation. Book a demo and we will walk you through it and set you up. Everything below describes the app you get.

Where it runs

Desktop app

The whole workspace on macOS, Windows or Linux. Available now.

Chrome extension

A chat side panel, the app on every new tab and control of Chrome. Available now.

Browser tab

Coming soon: Zod in a browser tab on a computer that runs it.

Self-hosted & CLI

Coming soon: a container behind a password, and a command line.

Your first ten minutes

1

Link a model

Open Settings, then Model provider. Enter your provider’s address and API key (OpenRouter, OpenAI, or a local server such as Ollama or LM Studio), press Test connection and pick a model.

2

Say hello on Home

Home is one prompt box. Hover it to open it into your places: model, search, vault, routines, chats, connectors and settings. Ask for something real, like a short brief on a topic.

3

Watch it work

The agent shows each tool step in one card (“Used 3 tools”). Anything that changes something stops at an Allow and Deny card first.

4

Make a routine

Open Routines (in:routines or the sidebar), press New routine, choose who does it and when, and write what it should do. Test it, then save.

5

Teach it something

Say “remember that I like short answers”. It appears in Routines, then Memory, and Zod finds it again whenever it matters.

6

Add Chrome

Get the extension from the app (chat side panel, Environment, Browser), load it once in Chrome, and it pairs by itself.
