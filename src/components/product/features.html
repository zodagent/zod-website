Home & chat

A chat that does the work

Home is a greeting and one prompt box. Hover or focus it and it opens into your places: model, search, vault, routines, chats, connectors and settings. Chats stream in as they are written, and the sidebar can be full, icons only or hidden.

  • Attach files, mention a memory or an agent with @, run a skill with /, dictate by voice
  • Queue a message while it works, or steer the agent now
  • A context meter shows how much of the model’s window is used and by what
  • Right-click anywhere for quick actions that fit where you are

Tool steps & approvals

Every step shown. Every change asked first.

The agent uses real tools and shows each one in a single quiet card, such as “Read 2 files, ran 1 command”, opened to see the steps, their output and whether they failed. Anything that writes, deletes, installs or schedules stops at an Allow and Deny card.

  • Looking (reading, searching, listing) asks nothing
  • Ask first is on by default; Auto is one switch away
  • Terminal, Browser and Remote control are off until you switch them on
  • Per-tool permission for connectors: off, ask or allow
Read about tools & approvals
Approvals

You are always asked

An approval says what is about to happen before it does, and what it did afterwards. Questions with choices (“which one do you mean?”) appear as a card you click, so the agent never guesses between similar things.

  • Allow or Deny, with the exact command or change shown
  • Choices for ambiguous requests
  • Every run is recorded so you can see what happened
  • Acts only on what you named; says so when it does not exist

Answers you can act on

Tables, charts, forms and cards, in the chat

Zod draws structured answers in the chat itself: tables of rows, figures, charts, lists, forms, buttons, timelines, boards and detail cards, all from one grammar. A connector’s results look like Zod without shipping any design.

  • Code blocks with a copy button; files you can download
  • Forms the agent shows to ask for several things at once
  • Copy, save and retry on every answer
  • A block that cannot be drawn says why instead of failing quietly

Search

One bar for everything

Search finds chats, routines, pages, settings, memory, docs, help and every connector’s records. Words match like grep with a typo allowed; filters such as in:, is:, after: and sort: narrow, and | do: acts on what was found.

  • Ask a plain question and get it answered from the docs and help
  • The same language is used by routines and by the agent
  • Save a search as a view
  • Everything in Settings can be found by name
Read about search
Routines

Work that runs on its own, on a calendar

A routine says who does it, what it does and when it runs. The Routines page is a month calendar of what ran and what will, with a Coming up list and a colour per routine.

  • Start by hand, once, every few minutes, daily, weekdays, weekly, or when something happens
  • Thirty-two ready-made routines in seven groups to start from
  • Durable runs: a run cut off by a stop is reported, not repeated
  • Results are kept, and you are notified when a run finishes or fails
Read about routines
Write a routine

Who, what, when. Then test it.

A routine opens on a page of its own. Choose Zod or one of your agents, write what to do in words or as steps, choose when, and press Test the steps to run them without changing anything.

  • Make or change an agent right on the page
  • Steps in the Zod language: find, act, say, ask, decide, load a skill, hand to an agent, repeat
  • Date and time pickers that fit the window
  • “How steps are written” shows every kind with an example
Read about steps
Memory

What Zod remembers, in plain notes

Say “remember that…” and Zod keeps it as a note you can read, edit and forget. Routines and chats find memories by their words, and you can attach one by name with @.

  • Add, read, edit and forget from the Routines page
  • Found again by their words; docs and help are searched the same way
  • Saved from the Chrome extension: an answer, or the page you are reading
  • Kept in your vault and included in backups
Read about memory
Agents

Roles with their own tools and instructions

Ten starter agents (Researcher, Editor, Code reviewer, Planner, Bookkeeper, Coder, Browser operator, Operator, Librarian, Analyst), or make your own. Each has instructions, skills and the tools it may use.

  • Mention an agent with @ in a chat, or pick it in a routine
  • A sub-agent’s chat sits under the chat that started it
  • AI assist writes and tightens instructions
  • No tools picked means every tool; pick some and it gets only those
Read about agents
Skills

Know-how it loads when a request matches

A skill is saved instructions, such as how you close the month. Run one with /name, or let the agent load it when your request matches.

  • A catalog to switch on, and your own to make
  • Upload or paste a SKILL.md, or import one from GitHub
  • AI assist writes and edits skills
  • Attach skills to an agent
Read about skills
Connectors

Your own apps, through MCP

Paste a GitHub link or a folder and Zod installs the connector, starts it and shows its tools. A catalog of MCP servers is one switch away, and every tool is off, ask or allow.

  • Four kinds: built in, app, server and pack
  • The agent can add, write and remove connectors for you, asking first, and each change can be undone
  • Books adds accounting, stock and payroll, with Clinic, School, Dispatch, Legal and Stays modules
  • Zod is an MCP server too, so Claude Code and others can operate it
Read about connectors
Messaging

Talk to Zod from your chat apps

Pair your Telegram, Slack or Email and use the same agent from your phone. Only people you have paired can use it, and a routine can send its result to a channel.

  • Telegram, Slack and Email, with Discord, Matrix, Mattermost, ntfy, IRC, Signal, WhatsApp, Teams, Google Chat, WeCom, Feishu and DingTalk available
  • A stranger gets a short code that you approve in Zod
  • Files out and streamed answers on the main channels

Chrome extension

Zod inside Chrome

A chat side panel made for the browser, a small Zod tab on each website and an agent that can use your tabs. It pairs with the desktop app by itself, so it is the same agent, model and memory.

  • The panel knows the page title, address and your selection, and its text on request
  • Manage Chrome: tabs, windows, tab groups, bookmarks, history, downloads and recently closed
  • Remember an answer, or save a page to memory, in the desktop app
  • Made for Google Chrome 116 or newer

Code

Work in a folder, with a safety net

Choose a working folder and the agent reads, searches, edits and tests the project, runs commands when the terminal is on, and shows what it changed. Checkpoints let you step back.

  • Read, search, glob, edit, move and delete inside the folder only
  • git and project scripts
  • Terminal: start, read, write and stop long jobs
  • Remote control: see the screen and use the mouse and keyboard, when you switch it on

Chat details

What this chat is using

The details panel opens inside a chat and shows the model and working folder, what the agent may use, whether it asks first, how the context window is spent, and which connectors are on.

  • A context bar split into messages, tool results, connector tools, skills and the system prompt
  • Compact the chat to free room
  • Switches for Terminal, Browser and Remote control
  • Shows only in a chat, and only for that chat
Read about the details panel
Vaults

Separate workspaces

A vault has its own chats, routines, memory, agents, skills, connectors, settings and look. Switch from the title bar; each keeps running while you are in another.

  • Each vault keeps its layout: folded cards, panel and composer sizes, recent searches, theme
  • Backup and restore a whole vault; a backup never contains keys
  • Name, icon and colour per vault
Read about vaults
Settings & themes

One clean settings page

Your name, start page and search engine; what the agent may reach; the model; appearance with colour themes, wallpaper, blur and text size; seven languages; backup; and a danger zone to uninstall.

  • One layout for every form: a small label, a field and a clear focus ring
  • Wallpapers behind the app
  • English, Spanish, French, German, Arabic, Urdu and Hindi

Model

Any OpenAI-compatible model

Link OpenAI, OpenRouter or a local server such as Ollama or LM Studio. Test the connection, pick a model, and change it from the chat at any time. Your key stays on your computer and is never in a backup.

  • A searchable model list in the composer
  • Clear messages when a provider is rate limited or down
  • Routines written as steps run even with no model
Read about models
Notifications

Told once, clearly

A bell and a Notifications page keep what Zod told you: routine runs, errors and toasts. Open one for its full detail and a button that goes to what it is about.

  • Routine finished or failed
  • App errors explained in plain words
  • A quiet toast, at the bottom right, for small confirmations

Books & business modules

Run a business from the same chat

Books is an app connector for accounting, stock, payroll and several companies. Clinic, School, Dispatch, Legal and Stays are modules of Books. Ask in plain words; every change waits for your approval.

  • Clinic: book an appointment (a provider cannot be booked twice), record the visit and bill it
  • School: enrol a student (a full course refuses more), record attendance and grades
  • Dispatch: create a delivery, assign a driver and a vehicle that can carry it, track it to delivered
  • Legal: open a matter, log billable time, keep client money in a trust ledger that cannot go below zero
  • Stays: book a unit for dates (overlaps are refused), check guests in and out, schedule housekeeping
