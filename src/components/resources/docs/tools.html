Tools & approvals

The agent has nearly a hundred built-in tools, plus every tool your connectors offer. It reads before it states a fact, and asks before anything changes.

What it can use

Websearch the web and read a page
Filesread, write and list files, and give you a download
Code in a folderlist, read, search, edit, move and delete files in your working folder, run commands and git, with checkpoints to undo
Search and showrun any search or chain, and draw tables, charts and cards in the chat
Skills & sub-agentsload skills, hand a job to a sub-agent
Routines & memorymake, test and run routines; remember, recall and forget
Browserread and act in your Chrome tabs, and manage Chrome itself (with the extension)
Terminalrun commands and keep long jobs running (off until you switch it on)
Remote controlsee the screen and use the mouse and keyboard (off until you switch it on)
Connectorsevery tool your MCP servers and apps offer, and tools to add, write and remove connectors

The switches

Terminal, Browser and Remote control are separate switches in the chat details panel (or in Settings). Each is off until you turn it on. The working folder is chosen per chat, and the agent can only reach that folder.

Asking first

  • Anything that writes, deletes, installs, reconfigures or schedules shows an Allow and Deny card first. Looking (reading, searching, listing) asks nothing.
  • Ask first is on by default. Switch to Auto (⌘⇧A) and actions go ahead without a card.
  • For each connector tool you can choose off, ask or allow.
  • The card says what will happen, and the result says what did.

Never guessing

The agent is told never to state a figure, name, status or date it did not read from a tool in the conversation. If a tool returns nothing, it says so. It acts only on what you named, and if the thing you named does not exist it says so rather than acting on a similar one.
