Memory

Memory is what Zod remembers about you and your work: plain notes you can read, edit and forget, found again by their words.

Add a memory

  • Say “remember that…” in any chat and the agent keeps it.
  • Open Routines, then Memory (in:memory, ⌘⇧M) and press New memory.
  • From the Chrome extension, press Remember on an answer, or save the whole page you are reading.

How memories are used

When a request matches a memory by its words, Zod puts it in front of the model. Mention one by name with @[Title] to attach it to a message. The agent can also save and recall memories on its own, and tells you when it does.

Look after them

  • Open a memory to read it, edit it as text, or have the model help you tighten it.
  • Forget a memory and it is deleted; Zod will not find it again.
  • The Routines page shows the latest few; the Memory page lists them all with tags.

Docs and help are searchable too

The product docs and help are searched from the same bar as your memories. Type a question, or a few words, and the best matches come first; a docs result opens in a reader over whatever page you are on.

Private by design. Memory is stored in files on your computer, in your vault, and is included in backups.
