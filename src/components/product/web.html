A browser tab, coming soon

Open Zod in a tab on a computer that runs it, and use the full app: chat, search, routines, memory and connectors. Until then, use the desktop app or the Chrome extension.

Use it today on desktop

Open & chat

Link a model once, then start chatting. No account to create.

No Zod server

There is no Zod cloud holding your work, and no sign-up. The app runs on your computer.

Local-first

Chats, routines, memory and settings are saved in files on your computer, in a vault you can back up.

Self-hosted, with a password

Planned: run Zod in a container behind a password on your own server, so your team or your phone can reach the same workspace.

On your server

One container, one data volume, and a login in front of it.

Your data in one volume

Everything the app saves is in one place you can back up and restore.

Routines keep running

Routines run on the server on their schedule, and their results are waiting when you open it.

Phone-friendly

The layout adapts to a phone width, so the workspace works from a small screen too.

A command line, coming soon

A Zod command line is planned too: run a routine, ask a question or search from a terminal, with the same agent, memory and approvals.

OpenAI, OpenRouter, Ollama, LM Studio: anything that speaks /v1/chat/completions. Link one, and change the model from the chat at any time.
