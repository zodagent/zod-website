Connectors & MCP

Connectors are how Zod is extended: a program Zod starts and speaks MCP to, an app with its own pages, or a pack of skills and docs. Zod is also an MCP server, so other tools can use it.

Four kinds

Built in

What comes with Zod: Operations, Routines, Memory and Connectors themselves.

App

A connector with its own pages, settings and program, such as Books for accounting.

Server

Any MCP server. Its tools appear to the agent.

Pack

Only files: skills, pages and docs. Nothing runs.

Add one

1

Open Connectors

Type in:connectors or press ⌘9. A catalog of MCP servers is there to switch on.

2

Paste a link

Paste a GitHub link, or choose a folder. Zod installs it, starts it as a child process and shows its tools.

3

Or add your own

Press Add your own and give a name, the command and its arguments (for example npx -y @modelcontextprotocol/server-filesystem ~/Documents).

4

Set what each tool may do

Every tool is off, ask or allow. Installing code always asks first.

The agent can add, write and remove connectors for you too, asking first, and every change to a connector can be undone.

Books and business modules

Books is an app connector for accounting, stock, payroll and several companies. Clinic, School, Dispatch, Legal and Stays are modules of Books: book an appointment (a provider cannot be booked twice), enrol a student, assign a delivery, keep client money in a trust ledger, check in a guest. Ask in plain words; changes wait for your approval.

Messaging channels

Talk to Zod from your chat apps. Telegram, Slack and Email run today, with Discord, Matrix, Mattermost, ntfy, IRC, Signal, WhatsApp, Microsoft Teams, Google Chat, WeCom, Feishu and DingTalk available as channels. Only people you have paired can use it: a stranger gets a short code that you approve in Zod. A routine can send its result to a channel.

Zod as an MCP server

Zod serves MCP at /mcp so tools like Claude Code can operate it. Reads are free, a change needs confirm: true, and a connection over a network is read-only.

claude mcp add --transport http zod http://127.0.0.1:8790/mcp
