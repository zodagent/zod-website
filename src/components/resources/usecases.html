Personal research agent

Use Zod as a research workspace: enable a web search tool, ask questions, and have the agent dump findings into persistent Notes and Data. Sessions, memory, and outputs all live locally.

Tools docs

Self-hosted coding helper

Point Zod at a local model (Ollama or LM Studio) and keep everything on your machine. Use code_tools for JSON/YAML work, the code block renderer for output, and Approve/Reject confirmation plans before anything runs.

Providers docs

Task scheduler with AI follow-up

Schedule prompts once, on an interval, daily, or weekly. Each run goes through the full agent loop — tools included — and can even execute a whole workflow harness. With the service worker, runs continue while the tab is closed.

Scheduler docs

Demo & teaching harness

The orchestrator and card renderers make Zod a great way to demonstrate tool-calling, structured output, and confirmation flows — without standing up any backend. Ideal for workshops and classes.

Orchestrator docs

Desktop & extension utility

The same local-first app ships as a Chrome extension that controls the full browser and a desktop app that controls the desktop. Your sessions and settings move with you via export/import.
