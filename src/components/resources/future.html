Roadmap

What Zod ships today and what is next. We keep this page honest: shipped means shipped, planned means planned. Zod is in beta.

Shipped today

Chat that does the work

Done

An agent that uses nearly a hundred tools, reads before it states a fact and asks before it changes anything.

Routines

Done

Who does it, what it does and when it runs, with a calendar, dry-run tests and durable runs.

Memory, agents and skills

Done

Notes Zod keeps and finds by their words, agents with their own tools, and skills it loads on demand.

Connectors

Done

MCP both ways, a catalog of servers, install from a link, per-tool permissions and apps like Books.

Chrome extension

Done

A chat side panel, the app on every new tab, a Zod tab on each website and control of Chrome.

Vaults & backups

Done

Separate workspaces that each keep their data and look, with backup and restore.

What's next

Self-serve installers

Planned

Today Zod is available by invitation, set up with you in a demo. Self-serve installers for macOS, Windows and Linux are planned once they are signed and tested on each system.

Browser, self-hosted and CLI

Coming soon

Zod in a browser tab, in a container on your own server behind a password, and a command line for routines, questions and search. Coming soon.

More hours on messaging

Planned

Telegram, Slack and Email channels run today. The others, such as Discord, Matrix and Signal, are planned to get more real-world testing before they are listed as steady.
