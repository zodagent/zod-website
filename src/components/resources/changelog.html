Changelog

See what is new in Zod. Zod is in beta, so versions are named for what changed.

Beta 2 · Extension 1.6 Beta

Home, vaults and context

A simpler Home, a vault list you can pick from right there, and the chat's context where you want it.

  • A simpler Home box — click it and it opens to two chips (the model and the vault), four places (Search, Routines with a +, Connectors, Settings) and your last three chats. Nothing is said twice, the arrow keys walk the list, and it fits any width.
  • Pick a vault from Home — the vault chip drops its list in the box. Choose one and the whole window is in it, or make a new vault.
  • Context on your terms — the chat's context panel starts closed, never shows on Home or in an empty chat, and a chat from the Chrome side panel never opens it.
  • Context in the Chrome side panel — a button at the top switches the panel between the chat and its context: the model, what Zod may use, how full the window is, and the connectors.
  • No app on every new tab — new tabs are Chrome's own again; Open web view in the toolbar popup opens the whole app when you want it.
  • Quieter toasts — small confirmations are neutral cards at the bottom right with a coloured dot, and a line that shows how long they stay.
  • One View more — the wallpaper picker has a single button that shows the rest of the tiles, then fetches more.
Extension 1.4 Beta

All of Chrome, Chrome only

The Chrome extension is made for Google Chrome 116 or newer and can now manage Chrome itself, not only pages.

  • Manage Chrome — pin, mute, move and group tabs, manage windows, bookmarks, history, downloads and recently closed tabs (browser_tab_actions, browser_bookmarks, browser_history).
  • Side panel — a chat made for the browser, with the model picker and Ask first at the top, files, a picture of the page and dictation. Type @, /for memories and skills, and save answers or pages to Zod's memory. It pairs with the desktop app by itself, shows a green dot on the toolbar icon when connected, and has a switch for Ask first.
  • Zod tab on every website — a small logo tab on each page that says what the agent is doing, and opens the panel with Alt+Z or the toolbar.
  • Web view — open the whole Zod app in a tab from the toolbar popup when you want it. Install in Zod from a right-click on a GitHub link.
Routines Beta

One page for everything Zod does on its own

Schedules and flows became Routines: who does it, what it does, and when it runs, on one page.

  • Calendar — a month view of what ran and what will, with a Coming up list and a colour per routine.
  • Steps — Write steps in the Zod language, test them with a dry run that changes nothing, and read how steps are written beside the editor. , ,
  • Who and when — choose Zod or one of your agents, and start by hand, once, every few minutes, daily, weekdays, weekly or when something happens.
  • Durable runs — a run cut off by a stop is reported, not repeated, and each run keeps its result.
  • Memory — what Zod remembers now lives in Routines, with the latest notes on the page and a full list to add, edit and forget.
Vaults Beta

Each vault keeps its own look

A vault is a separate workspace. Each one now keeps everything of its own, including how it looks.

  • Saved layout — folded cards, panel and composer sizes, recent searches and theme hints are saved with the vault, so it comes back the same in any window.
  • Backups — a backup includes it, without keys or passwords.
  • Switching — switch, make and edit vaults from the vault button in the title bar.
  • Search — docs, help and memory are found by their words from the one search bar.
  • Beta — what is steady, what is changing and the known limits are listed in the docs.
Chat Beta

Approvals, tool steps and answers you can act on

  • Tool steps — one quiet card per answer, “Used 3 tools”, opened to see each step. ,
  • Rendered answers — tables, charts, figures, forms and cards drawn in the chat, with copy and retry on every answer.
  • Allow and Deny — a card says what is about to happen before anything changes, and the model picker sits in the composer.
  • Clean forms — every form uses one clear layout: a small label, a field, and a focus ring.
  • Pickers — date and time pickers fit the window as one solid card.
First beta Beta

Zod, local-first

Zod is a local-first agent workspace: one app for chat, search, routines, memory and connectors.

  • Any model — works with any OpenAI-compatible API: OpenAI, OpenRouter, and local servers like Ollama or LM Studio.
  • Local-first — chats, routines, memory and settings live in files on your computer. No account, no Zod server.
  • Tools — nearly a hundred built-in tools, for example memory, search, files, web, routines, browser, approvals, connectors skills.
  • Asks first — anything that writes, deletes, installs or schedules asks first. Looking runs on its own.
  • Routines — start by hand, once, on a timetable or when something happens; results are kept with notifications.
  • Connectors — MCP in both directions, a catalog, per-tool permissions, and apps like Books.
