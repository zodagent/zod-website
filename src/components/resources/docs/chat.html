Chat & context

A chat is a conversation with an agent that can use tools. It streams its answer, shows what it did, and asks first.

Home and chats

Home is a greeting, the time and one prompt box. Your chats are listed in the sidebar, newest first; search finds them by title and by what was said. The sidebar can be full, icons only, or hidden (⌘\).

The composer

  • + menu: attach files, add a picture, mention a memory, agent or another chat with @, run a skill with /, or turn the chat into a routine.
  • Voice: dictate a message; it is transcribed by your model provider.
  • Resize: drag the corner to make the box taller or wider; Escape gives the size back.
  • Queue and steer: press Enter while it works to queue a message; press ⌘↵ to steer the agent now.
  • Model and Ask first: chips under the box change the model and whether actions ask first.

What the agent shows

  • Tool steps: one quiet card per answer, such as “Read 2 files, ran 1 command”, opened to see each step, its result and whether it failed.
  • Approvals: an Allow and Deny card says what is about to happen before it does, and what it did afterwards.
  • Rendered answers: tables, charts, figures, lists, forms and cards drawn in the chat, and files you can download.
  • Actions on an answer: copy, save, retry; edit and resend your own messages.

The chat details panel

Press ⌘I inside a chat to open its details: the model and working folder, what the agent may use (Terminal, Browser, Remote control), whether it asks before acting, how much of the context window is used and by what, and the connectors that are on. It shows only in a chat, and only for that chat.

Context and long chats

The context meter shows messages, tool results, connector tools, skills and the system prompt as a share of the model’s window. When a chat grows long, Compact this chat (⌘⇧K) summarises its older part to free room.

Quick actions

Right-click anywhere for a menu that adapts to where you are: actions for this chat or this search first, then Start, New and Go to.
