Solution

A local-first agent workspace that does the work, and asks first.

Zod runs on your computer. Chat with an agent that uses real tools, search everything from one bar, set routines that run on their own, keep memory, and connect your own apps. It works with any OpenAI-compatible model, including a local one. No account, and your data stays in files on your computer.

On screen · Approvals

The core of the answer: a chat that acts with real tools, and an Allow and Deny card that says what it is about to do.

See how it works

How it answers the problem

Chrome extension

It runs where the work is

A desktop app for Linux, macOS and Windows, and a Chrome extension with a chat panel beside any page. Files, browser and apps are right there.

Approvals

It asks before it changes anything

Ask first is on by default. Allow or Deny, with the exact command or change shown, and a record of every run.

Model

It works with any model

Any OpenAI-compatible endpoint, including local ones. Switch models without losing chats, memory or routines.

Search

One bar for everything

Search chats, routines, pages, settings, memory, docs and every connector’s records, with filters and verbs that act on what was found.

Routines

Routines that run on their own

Who does it, what it does, when it runs, and a dry run to test it. A month calendar of what ran and what will.

Connectors

Your own apps and connectors

MCP servers, apps and packs, with a permission per tool: off, ask or allow. Books adds accounting, stock and payroll.

Your chats, routines, memory, settings and connectors live in files on your computer, in a vault you can back up or switch. The only traffic that leaves is what you send to the model you link and the connectors you add.
