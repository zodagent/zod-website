Your first run

Getting started takes about a minute.

1. Open the app

Launch Zod Agent in the browser, as an extension, or as a desktop app — it's the same workspace.

2. Add a provider

Open Settings → Providers, add an OpenAI-compatible API (OpenAI, OpenRouter, Together, Groq, Ollama, LM Studio...), and set it as your default.

3. Pick a model & chat

Choose a model, then start chatting on the hub. Try slash commands, mentions, tools, or schedule a prompt to run later.
