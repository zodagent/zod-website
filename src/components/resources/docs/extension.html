Chrome extension

Zod inside Chrome: a chat panel beside any page, the Zod app on every new tab, a small Zod tab on each website, and an agent that can use your browser. It is made for Google Chrome 116 or newer.

What you get

Side panel

A chat made for the browser. It sees the page title, address and your selection, and the page text when you turn on Read page.

New tab

Every new tab opens the whole Zod app, in step with the desktop app. Switch it off in the toolbar popup.

A Zod tab on every site

A small logo tab on the right edge says what the agent is doing in the page and opens the panel. Drag it along the edge.

Control of Chrome

Read, click, type, fill forms, scroll and take pictures in your tabs, logged in as you.

The side panel

  • Open it from the toolbar popup, with Alt+Z, from the tab on a page, or right-click and choose Open Zod side panel.
  • The model picker and Ask first are at the top; the message box has the + menu for files, a picture of the page and dictation, @ for memories and / for skills.
  • Each answer has Copy, Remember (save it to Zod’s memory) and Retry, and the + menu can save the page you are reading to memory.
  • Chats from the panel are saved by the desktop app and appear in its chat list.

Managing Chrome itself

Tabspin, mute, move, duplicate, discard, zoom, switch, close
Windowslist, create, focus, resize, maximize, close
Tab groupsgroup tabs by topic, name and colour a group, collapse, ungroup
Bookmarkssearch, add, edit, remove
Historysearch by words and days, delete an address
Downloadslist, start, pause, resume, show, open
Recently closedlist and restore

Looking asks nothing; anything that changes something asks first unless Ask first is off. Browser pages such as chrome:// and the Web Store cannot be controlled.

Set it up

1

Get the extension from the app

In a chat, open the details panel, Environment, Browser, and switch Browser control on. Press Get the extension and unzip it.

2

Load it once

In Chrome open chrome://extensions, switch on Developer mode, press Load unpacked and choose the folder.

3

It pairs by itself

The extension finds Zod on this computer and takes the pairing token; the toolbar icon shows a green dot while connected. If it cannot, paste the token under Advanced in its popup.

After an update, press the reload arrow on the extension’s card so Chrome grants any new permission. The extension is for Chrome only.

Install both ways. The app hands out the extension, and the extension points to the Zod app when it is not running. Right-click a GitHub or GitLab link and choose Install in Zod to add a connector (you confirm, and Zod asks again).
