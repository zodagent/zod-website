Enterprise & self-hosted.

Zod Agent is client-side by design — there is no cloud to sign up for and no data that has to leave your network. Deploy the static build internally, connect your own OpenAI-compatible gateway, and your team gets a full agentic workspace that never touches our servers.

The entire app — sessions, memory, tools, workflows, scheduler, and provider config — runs in the browser. Your only outbound traffic is the LLM requests you explicitly send to the endpoints you configure.

Self-hosted static build

Deploy Zod Agent anywhere a static site can be served — a CDN, an intranet server, or an air-gapped environment. No backend to run, no dependencies to patch.

Data stays on your network

Point Zod Agent at an internal OpenAI-compatible gateway or a local model server. Conversations never leave your perimeter.

MCP-over-HTTP

Connect internal MCP servers over HTTP to give agents access to your own systems — no infrastructure to install on the desktop.

Workflows & orchestrator

Script repeatable agent behaviors with YAML workflows and the orchestrator, so results are consistent across the team.

Custom tools in JavaScript

Write bespoke tools for your internal APIs and services and drop them into the workspace for every agent to use.

Background scheduler

Schedule agents to run in a service worker — digests, checks, and reports on a timer, with nothing running on a server.
