Routines, in one place

Write what a routine does as a few lines, one step each: find, act, say, ask, stop. Then test them with a dry run and run them for real.

Learn about routines

A small routine, ready to run:

in:notifications is:error is:unread say: {{count}} unread errors: {{names}}

Schedule work, and see it on a calendar

Run a routine by hand, once, every few minutes, daily, on weekdays, weekly, or when something happens. A month calendar shows what ran and what will, and each run keeps its result.

Learn about routines

Many ways to start

By hand, once, repeating, daily, weekdays, weekly or on an event, with run now and pause.

Who does it

Zod, or one of your agents. A routine's run never takes over the window you are working in.

Durable runs

A run that was cut off by a stop is reported, not repeated, and notifies you when it finishes or fails.
